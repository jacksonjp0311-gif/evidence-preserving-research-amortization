# Evidence-Preserving Research Amortization

**Working paper v1.1 · 2 November 2026 · Not peer reviewed**

This release contains an independent theoretical proposal for amortizing repeated research through versioned, source-linked evidence packets. It distinguishes retrieval, verification, freshness, rights, maintenance, and fallback costs.

## Files

- Evidence_Preserving_Research_Amortization_White_Paper_v1.1.pdf — the revised 18-page paper.
- model.py — standard-library Python script for the illustrative equations, sensitivity table, and SVG figures.
- data/sensitivity.csv — computed values at eligible-reuse rates of 30%, 50%, 70%, and 90%.
- figures/ — SVG curves generated by model.py.
- media/ — prepared X preview card and a break-even figure crop.

Run python model.py --output-dir . from this directory to regenerate the CSV and figures.

## Scientific status and limits

This is a theoretical working paper and an experimental agenda, not an empirical demonstration. Every numerical value in the model is synthetic. In particular, the example's 38.6% modeled cost reduction is an arithmetic consequence of declared assumptions; it is not a measured GPU, energy, latency, or dollar saving. The 600-query count is described as a pilot target, not a powered confirmatory sample.

The original LaTeX project was not present with the supplied Desktop PDF. This release preserves the original paper's main body and adds the corrected probability definition, reference repairs, a related-work boundary, a prospective preregistration protocol, and the reproducibility script.

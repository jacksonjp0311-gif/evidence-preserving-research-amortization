## About the paper

The paper proposes amortizing repeated research through versioned, source-linked evidence packets with explicit quality, freshness, rights, verification, maintenance, and fallback costs. It defines a formal cost model and a prospective experimental program for evaluating the proposal.

## Scientific status and limits

This is a theoretical working paper and experimental agenda, not an empirical demonstration. The numerical inputs are synthetic. The example's 38.6% modeled cost reduction follows from its declared assumptions; it is not a measured GPU, energy, latency, or dollar saving. The 600-query figure is a proposed pilot target, not a powered confirmatory sample.

The supplied Desktop PDF did not include the original LaTeX project. This repository therefore contains the paper PDFs and the reproducibility model, data, and figures, but not the original typesetting source.
